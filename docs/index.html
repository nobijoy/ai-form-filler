AI Form Filler

Fill reactive and multi-step forms with realistic synthetic data.

Built for framework-controlled inputs that revert naive writes, and wizards whose later fields must match earlier answers. Bring your own LLM key.

Start the tutorial View on GitHub

What it handles

Reactive frameworks

Native property setters and real events so React, Vue, Svelte, and Angular keep the value.

Multi-step wizards

Auto-advance with content fingerprints and cross-step identity for confirmations.

Hybrid or offline

Heuristics plus AI by default — or heuristics-only when you have no API key.

Your keys stay local

Credentials live in the service worker. The page being filled never sees them.
